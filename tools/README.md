# 🧰 tools

본 디렉토리는 개발/운영 유틸리티 스크립트와 성능/관측 도구 구성을 형상 관리합니다. 목표는 반복 가능하고 문서화된 실행을 제공하여 실수를 줄이고 유지보수 비용을 낮추는 것입니다.

---
## 📐 구성 원칙
- 실행은 항상 스크립트로 기록하고, 옵션/환경 변수는 파라미터화합니다.
- 공통 변수는 `.env` 파일 또는 실행 스크립트 파라미터로 주입합니다.
- 외부 의존(k6, Loki 등)은 버전/설치 방법을 README에 명시합니다.
- 로컬/원격 환경 차이는 `BASE_URL` 등 환경 변수로만 분기합니다.

---
## 🗂️ 디렉토리 가이드
- `perf/`: 성능 시험 도구
  - `k6/`: 부하 테스트 스크립트와 실행 도구
    - `scenarios/`: 시나리오별 k6 스크립트
    - `data/`: 테스트 데이터 파일(CSV 등)
    - `env/`: 환경 변수 예시/샘플
    - `results/`: 실행 결과(JSON 등)
    - `run.ps1`: 표준 실행 스크립트(Windows PowerShell)

---
## 🔧 변경/운영 지침
- 신규 스크립트/도구 추가 시:
  1) 목적/입력/출력을 README에 10줄 내외로 요약
  2) `.env.example`에 필요한 변수를 추가
  3) 예시 실행 커맨드를 1줄 이상 제공
- 파괴적 변경 시(PR 설명에) 변경점과 이전 사용법 호환성 여부를 명시합니다.
